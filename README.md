# Ruins Delver Prototype

Godot 4.x で `project.godot` を開き、実行してください。外部素材や追加プラグインは不要です。

- WASD / 矢印キー: 移動候補を選択
- Space / Enter / クリック: 選択中の候補マスへ移動
- Q / E: 武器と移動パターンを切り替え
- R: 向きを時計回りに回転
- G: マップを再生成
- 22部屋を目標に毎回ランダム生成
- 通路幅は3マス
- 茶系が自然洞窟・遺跡、青緑系が低確率の旧文明施設部屋
- プレイヤーは整数マスに着地し、ハンマーは歩、剣は銀、斧は桂馬として移動
- 絵がある武器の移動パターンだけに切り替え可能

`DungeonGenerator.rooms` は各部屋の矩形、中心座標、種別を保持しています。将来はこの情報を使い、通常部屋に探索アイテム、施設部屋に端末、特定部屋に同業者NPCや闇市ゲートを配置できます。
